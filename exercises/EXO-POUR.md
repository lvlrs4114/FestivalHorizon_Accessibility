# Exercice POUR

Sans modifier le code, classez ces **4 situations** selon le **principe POUR principal** ; pour chacune, précisez l'impact sur une personne et un test concret.

1. Une image qui porte une information essentielle n'a pas de texte alternatif.
2. Une fenêtre modale ne peut pas être quittée au clavier.
3. Un formulaire affiche « invalide » sans expliquer la saisie attendue.
4. Un `div` cliquable ne donne ni rôle ni état accessible.

Échangez vos réponses à l'oral : une situation peut toucher plusieurs principes, mais justifiez celui que vous retenez. **Aucune correction demandée.**
