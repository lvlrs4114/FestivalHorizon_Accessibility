# Exercices SEO — Festival Horizon

## Installation et commandes

```bash
npm install
npm run dev
npm run build
npm run preview
npm run seo:check
npm run seo:sitemap
npm run seo:http-demo
npm run seo:http-check
npm run seo:prerender
```

Lance les serveurs dans un terminal et les commandes de contrôle dans un autre. Pour les enquêtes, inspecte d’abord le site et note ton hypothèse, puis lance le script : certains diagnostics révèlent directement les anomalies.

## Outils

Navigateur avec DevTools, View Source, Lighthouse, terminal avec `curl`, éditeur de code. Pour TP5, un parseur JSON et un validateur Schema.org disponible.

## Organisation

Les TP se suivent sur le même projet : TP0 établit des preuves initiales ; les TP1–7 investiguent et corrigent ; TP8 réutilise les preuves. Le diaporama et les démonstrations occupent une part importante des deux séances : les exercices restants servent de réserve ou de travail complémentaire.

### Séance 1 — Comprendre et corriger les pages

Parcours essentiel : TP0.1, TP1.1, TP1.2, TP2.1, TP2.2, TP3.1.

### Séance 2 — Technique et vérification

Parcours essentiel : TP3.2, TP4.2, TP4.4, TP6.2, TP7.1, TP8.2.
